# ai-comic-drama

小说变竖屏短视频：把一本小说按章节拆成 5 秒一个的分镜，用视频模型逐镜生成，再用竖屏播放页像刷短视频一样看。

- `漫剧刷视频-竖屏播放页.html` — 11 镜头位竖屏播放器（视频放进同目录 `videos/` 即可播放）
- `漫剧-拆分镜.py` — 按章节自动拆分镜脚本（标准库 only）
- `查理九世-吸血古堡-第一章-分镜表.md` — 《查理九世·吸血古堡》第一章 9 镜分镜表
- `查理九世-吸血古堡-全书镜头清单.md` — 全书约 79 镜、成片约 6 分 35 秒的镜头清单

生成端用 Kaggle 免费 T4 跑 Wan 2.1 1.3B（图生视频），仅供个人观看。
